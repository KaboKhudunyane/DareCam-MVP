# DareCam design system

- **Mood:** live game show, not dating; dark ink background with electric lime, violet and coral accents.
- **Typography:** system sans with heavy display headings; sentence-case labels and high contrast.
- **Shape:** 20px cards, pill statuses, 1px translucent borders, soft glass panels.
- **Color roles:** `--ink` background, `--panel` surface, `--lime` action/success, `--violet` accent, `--coral` safety/warning, `--muted` secondary text.
- **Interaction:** clear focus rings, buttons with verbs, toast feedback, progress bars and reduced-motion support.
- **Responsive:** one-column player flow below 800px; host console becomes stacked; chat remains reachable.
- **Accessibility:** semantic landmarks, labelled controls, keyboard operation, no information by color alone, minimum comfortable touch targets.
